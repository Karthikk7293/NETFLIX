# NETFLIX

Netflix-inspired React browsing interface using the TMDB API for movie data and YouTube trailer previews.

## Project scope

This is a browsing-interface learning recreation, not a streaming service. Movie data requires TMDB configuration, and trailer previews use YouTube.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
npm install
npm run start
```

Other package scripts: `npm run build`, `npm run test`.
